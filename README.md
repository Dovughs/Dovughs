# Doruk

**Low-level systems, Windows internals and security research.**

I study how operating systems work beneath their public interfaces, from memory
management and kernel execution to hardware virtualization. My interests center
on understanding implementation details through source code, debugging and
controlled experiments.

### Technical interests

- **Systems programming:** C, C++, x64 assembly, and the Windows Native API.
- **Windows internals:** virtual memory, process and thread structures, PE files,
  kernel mechanisms, and debugging with WinDbg.
- **Virtualization:** Intel VT-x, per-CPU EPT, VM-exit handling, and preserving
  execution state across virtualization transitions.
- **EDR research and evasion:** studying endpoint telemetry, detection mechanisms,
  and evasion techniques in controlled lab environments.

### Featured project

**[Velum-VMM](https://github.com/Dovughs/velum-vmm)** is a Windows x64 research
hypervisor written in C and assembly. It combines Intel VT-x and EPT entry hooks
with live kernel telemetry, scoped request policies, and an interactive console.

The [technical write-up](https://github.com/Dovughs/velum-vmm/blob/main/readmes/technical-writeup/README.md)
covers the architecture, implementation decisions, and Windows compatibility
investigations with source excerpts and debugger output.
